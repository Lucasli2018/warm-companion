# 温暖陪伴 · Warm Companion

一款沉浸式毛玻璃风格的情感陪伴聊天 App 界面原型，由虚拟角色「阿溪」（温柔知性的学姐人设）提供日常问候、情绪疏导与鼓励打气。

> 单文件自包含原型，无需后端，离线双击即可运行。

## 特性

- **沉浸式全屏角色背景**：角色「阿溪」以全屏背景图呈现，配合渐变暗化叠加层保证文字可读性
- **毛玻璃（Glassmorphism）UI**：头部、快捷标签、输入框均采用 `backdrop-filter` 毛玻璃效果
- **移动端竖屏布局**：
  - 状态栏（动态时间 + 信号/Wi-Fi/电池图标）
  - 毛玻璃头部（汉堡菜单 + 角色头像/名称/在线状态 + 语音按钮）
  - 横向滚动快捷话题标签（心情不太好、想聊聊工作、随便唠唠、给我打打气…）
  - 半透明聊天气泡叠加在角色背景上
  - 毛玻璃输入区（纸飞机发送按钮）
- **侧滑抽屉**：点击汉堡菜单从左滑入会话列表（搜索 + 历史 + 未读红点）
- **丰富交互动效**：
  - 发送按钮飞行动画
  - 回复前 loading 三点跳动
  - 阿溪回复逐字打字机效果（带闪烁光标）
  - 消息气泡渐入动画
  - 在线状态脉冲呼吸灯
- **富文本 & 代码高亮**：支持 `**加粗**`、`*斜体*`、`` `行内代码` ``、` ```代码块``` `
- **mock 流式回复**：按话题关键词匹配温柔、积极、有分寸的回应
- **响应式**：桌面端展示手机外壳框架，移动端全屏铺满

## 设计风格

暖色调角色背景图（奶油 → 蜜桃渐变 + 暖棕色卷发角色）+ 深色半透明毛玻璃 UI 叠加，整体沉浸温暖治愈。

## 快速开始

直接双击 `index.html` 即可在浏览器中运行，无需任何依赖。

## 角色设定

**阿溪**，温柔知性的学姐，声音柔和，善于倾听，常带笑容。
她的职责是日常问候、情绪疏导、鼓励打气这类健康正向的陪伴对话，所有回复措辞积极健康、保持恰当分寸。

## 快捷话题标签

内置 8 个一键发起的暖心话题：

| 标签 | 说明 |
|------|------|
| 心情不太好 | 想找个人说说，不想一个人憋着 |
| 想聊聊工作 | 最近工作有点累，想吐槽一下 |
| 随便唠唠 | 没什么特别的事，就是想聊聊天 |
| 给我打打气 | 最近有点没信心，需要打气 |
| 有点焦虑 | 脑子里事情太多，静不下来 |
| 睡不着 | 翻来覆去，想有人陪我说说话 |
| 分享开心事 | 今天遇到了好事，想告诉你 |
| 有点迷茫 | 不知道接下来该怎么走 |

## 技术说明

- **技术栈**：原生 HTML + CSS + JavaScript（pure-static）
- **图标**：内联 SVG（Lucide 风格），零外部依赖
- **字体**：系统中文字体栈（PingFang SC / Noto Sans CJK SC / Microsoft YaHei）
- **背景图**：AI 生成的动漫风格暖色角色插画
- **数据**：全部 mock，`mockReply()` 函数按关键词匹配回复，可方便替换为真实 API

## 接入真实后端（可选）

当前所有 AI 回复由 `mockReply(userText)` 本地生成。若要接入真实模型，只需将该函数替换为异步调用：

```js
async function mockReply(userText) {
  const res = await fetch('/api/chat', {
    method: 'POST',
    body: JSON.stringify({ message: userText })
  });
  const data = await res.json();
  return data.reply;
}
```

并将 `sendMessage` 中的调用改为 `await mockReply(text)` 即可。
