# 温暖陪伴 · Warm Companion

一款温柔治愈风格的情感陪伴聊天 App 界面原型，由虚拟角色「阿溪」（温柔知性的学姐人设）提供日常问候、情绪疏导与鼓励打气。

> 📦 **交付物**：单文件自包含原型，无需后端，离线双击即可运行。

## ✨ 特性

- **温柔知性学姐「阿溪」**：声音柔和、善于倾听、常带笑容，负责健康正向的陪伴对话
- **三栏布局**：
  - 左栏 · 会话历史列表（角色头像、最近一句摘要、时间、未读红点、在线状态）
  - 中栏 · 聊天区（顶部角色名 +「在线倾听中」脉冲状态、气泡渐入、逐字打字机、富文本与代码块高亮）
  - 右栏 · 可折叠「暖心开场白」话题模板面板
- **丰富交互动效**：
  - 发送按钮飞行动画
  - 回复前 loading 三点跳动
  - 阿溪回复逐字打字机效果（带闪烁光标）
  - 消息气泡渐入动画
- **富文本 & 代码高亮**：支持 `**加粗**`、`*斜体*`、`` `行内代码` ``、` ```代码块``` `（关键字/字符串/注释着色）
- **mock 流式回复**：按话题关键词匹配温柔、积极、有分寸的回应，不接真实后端

## 🎨 设计风格

柔和暖色渐变背景（奶油 → 蜜桃）、圆润气泡、暖棕文字（非纯黑）、珊瑚色主调 + 鼠尾草绿在线色，整体温暖治愈。

直接双击 `index.html` 即可在浏览器中运行，无需任何依赖。

## 🤖 角色设定

**阿溪**，温柔知性的学姐，声音柔和，善于倾听，常带笑容。
她的职责是日常问候、情绪疏导、鼓励打气这类健康正向的陪伴对话，所有回复措辞积极健康、保持恰当分寸。

内置 8 个一键发起的暖心开场白：

## 🛠️ 技术说明

- **技术栈**：原生 HTML + CSS + JavaScript（pure-static）
- **图标**：内联 SVG（Lucide 风格），零外部依赖
- **字体**：系统中文字体栈（PingFang SC / Microsoft YaHei / Hiragino Sans GB）
- **数据**：全部 mock，`mockReply()` 函数按关键词匹配回复，可方便替换为真实 API

## 🔌 接入真实后端（可选）

当前所有 AI 回复由 `mockReply(userText)` 本地生成。若要接入真实模型，只需将该函数替换为异步调用：

```js
async function mockReply(userText) {
  const res = await fetch('/api/chat', {
    method: 'POST',
    body: JSON.stringify({ message: userText })
  });
  const data = await res.json();
  return data.reply;
}
```

并将 `sendMessage` 中的调用改为 `await mockReply(text)` 即可。
